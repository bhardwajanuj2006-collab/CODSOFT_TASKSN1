Titanic Survival Prediction
About the Project

This project predicts whether a passenger survived the Titanic disaster using machine learning.

Dataset

The dataset contains passenger information such as age, gender, ticket class, and fare.

Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn
Steps
Load the dataset.
Clean and prepare the data.
Analyze the data using graphs.
Train a machine learning model.
Predict passenger survival.
Objective

To learn how machine learning can be used to predict passenger survival.
